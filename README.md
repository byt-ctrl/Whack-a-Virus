
# Whack-a-Virus Game

Whack-a-Virus is a simple browser-based game with adjustable difficulty levels, sound effects, and theme options.

## Features

- **Difficulty Levels**: Choose from Easy, Medium, and Hard.
- **Sound Options**: 
  - `hit.wav` plays when you hit a virus.
  - `success.wav` plays when the game ends.
  - Option to turn off all sounds.
- **Theme Toggle**: Switch between Dark and Light themes.

## How to Play

1. Open the `index.html` file in your browser.
2. Select your difficulty level, sound setting, and theme preference.
3. Play the game by clicking the viruses to score points.

## Project Structure
```txt
whack-a-virus/

│   ├── hit.wav          // Sound when virus is hit

```
